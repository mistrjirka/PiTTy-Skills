# Optional prompt packaging

Use headings or delimiters when they separate real concepts or untrusted data. XML is an option, not a required style.

A useful contract identifies the outcome, evidence boundary, permitted actions, invariants and completion result. A tool contract identifies inputs, returned evidence, side effects and failure/retry semantics. Put each policy in its owning layer rather than copying a block catalog into every prompt.

Do not add framework blocks without a demonstrated task need. See [SKILL.md](SKILL.md) and [agent-loop.md](agent-loop.md) for the actual design decisions.
